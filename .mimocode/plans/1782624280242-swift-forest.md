# 代码改动方案：补齐工艺参数维度 + 验证实验闭环 + 过拟合检测

## 目标
1. 将扫描速度(Vs)和送粉速率(Vf)从固定值扩展为可变参数
2. 新增宽高比(W/H)评价指标
3. 建立优化→预测→验证→误差分析的完整闭环
4. 新增过拟合检测/正则化
5. 新增正交实验设计脚本（L25(5³)）
6. 先用模拟数据验证代码流程，后续替换真实数据

## 改动总览（6个文件 + 1个新文件）

---

### 文件1: `pipeline/data_integration.py`
**改动**: Vs/Vf从硬编码常量改为可变参数

当前问题: 第309-310行硬编码 `df['送粉速度(g/min)'] = 10`, `df['扫描速度(mm/s)'] = 10`

改动点:
- 硬编码区域改为从CSV已有列读取，若无则填入当前默认值（保持兼容）
- 新增列: `扫描速度(mm/min)`, `送粉速率(g/min)`, `送粉速度(r/min)`
- 新增 `generate_simulated_data()` 函数: 生成25组模拟正交数据供代码验证
- 模拟数据基于现有4组功率数据插值+噪声，确保流程可跑通

---

### 文件2: `image/picture_processing.py`
**改动**: 新增宽高比计算

改动点: `calculate_quantitative_data()`函数（第335-421行）
- 在晶粒尺寸计算后，新增宽高比计算
- 方法: 对熔覆层区域(seg_mask==1)做最小外接矩形，取宽度和高度
- 新增输出: `熔覆层宽度(μm)`, `熔覆层高度(μm)`, `宽高比(W/H)`
- 宽度 = 水平方向最大跨度 × pixel_size_um
- 高度 = 垂直方向最大跨度 × pixel_size_um

---

### 文件3: `pipeline/property_model.py`
**改动**: 特征工程扩展 + 过拟合检测

改动点:
- `load_and_prepare()`函数（第39-97行）:
  - `feature_groups`新增 `"process"` 组: `["扫描速度(mm/min)", "送粉速率(g/min)"]`
  - 新增交叉特征: `power_x_Vs`, `power_x_Vf`
  - 热输入公式修正: `heat_input = P / (Vs/60) / scan_spacing / 1000`（当前用固定300/60）
- `train_models()`函数（第101-148行）:
  - 新增过拟合检测: 训练集R² vs LOO-CV R²差值>0.1则警告
  - 新增正则化选项: GBR加`min_samples_leaf`约束, RFR加`max_depth`限制
  - 新增特征数量检查: 特征数/样本数 > 0.5 则降维警告
  - 新增学习曲线函数: 绘制训练集/验证集R²随样本数变化曲线

---

### 文件4: `pipeline/optimized_pipeline.py`
**改动**: 搜索空间3D化 + 验证方案完善

改动点:
- `make_predictor()`（第66-94行）:
  - `predict_hardness(power_w)` → `predict_hardness(params)` params=[P, Vs, Vf]
  - `heat_input` 改为: `P / (Vs/60) / scan_spacing / 1000`
- `make_defect_predictor()`（第97-107行）:
  - 缺陷率模型加入Vs/Vf影响
- `multi_objective_optimize()`（第111-134行）:
  - bounds: `[(700, 1800), (200, 400), (6, 14)]`
  - objective中提取多参数
- `sensitivity_analysis()`（第138-157行）:
  - 扩展为3D: P±200W, Vs±50mm/min, Vf±2g/min
  - 新增3张敏感性子图
- `generate_verification_plan()`（第287-359行）:
  - 补充3组验证实验完整参数(P, Vs, Vf)
  - 补充预测值±置信区间
  - 补充接受标准（误差<10%）
  - 新增验证结果记录模板

---

### 文件5: `image/picture_processing.py` (RegressionModels类)
**改动**: 过拟合检测集成

改动点: `RegressionModels`类（第793-1185行）
- `train_all_models()`方法（第976-1065行）:
  - 新增过拟合检测: 训练R² - CV_R² > 0.1 则打印警告
  - 新增特征数量约束: 特征数>样本数×0.5时建议PCA降维
  - KFold折数动态调整: `n_splits=min(5, len(y)//2)`
- `evaluate_models()`方法（第1124-1149行）:
  - 新增泛化间隙指标: `generalization_gap = train_R² - test_R²`

### 文件6: `scripts/orthogonal_design.py` (新文件)
**改动**: 新建正交实验设计脚本

功能:
- 生成L25(5³)正交表
- 3因素: P(700-1800W), Vs(200-400mm/min), Vf(6-14g/min)
- 5水平正交表
- 输出: CSV文件 + 打印实验方案
- 极差分析函数: 计算各因素对各指标的影响主次
- 方差分析函数(可选): ANOVA检验因素显著性

## 验证方案

每步改动后运行验证:
1. **步骤1**: 运行 `python pipeline/data_integration.py`
   - 检查CSV新增 `扫描速度(mm/min)`, `送粉速率(g/min)` 列
   - 检查模拟数据生成正常（25行×N列）
2. **步骤2**: 运行 `python image/picture_processing.py`
   - 检查CSV新增 `宽高比(W/H)` 列
   - 检查宽高比值合理（通常1-5之间）
3. **步骤3**: 运行 `python pipeline/property_model.py`
   - 检查SHAP输出包含Vs/Vf
   - 检查过拟合警告输出
   - 检查学习曲线图生成
4. **步骤4**: 运行 `python pipeline/optimized_pipeline.py`
   - 检查Pareto优化在3D空间运行
   - 检查验证方案包含完整(P, Vs, Vf)参数
5. **步骤5**: 运行 `python scripts/orthogonal_design.py`
   - 检查L25正交表生成
   - 检查极差分析结果

## 模拟数据策略

由于用户先用模拟数据验证:
- 基于现有4组功率数据(900/1200/1500W)的实测硬度
- 对25组正交组合，用物理公式+噪声生成模拟硬度
- 噪声: 正态分布N(0, σ=20HV)
- 确保模拟数据与真实数据量级一致
- 模拟数据保存在 `analysis_output/simulated_orthogonal_data.csv`
- 后续替换为真实实验数据时，只需修改CSV文件
