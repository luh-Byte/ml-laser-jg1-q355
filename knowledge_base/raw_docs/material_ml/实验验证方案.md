## 3. 验证实验设计

### 3.1 试样制备
- 基材: Q355低碳钢板
- 粉末: JG-1铁基自熔合金
- 工艺: 激光熔覆
- 扫描速度: 300 mm/min
- 扫描间距: 0.05 mm
- 每个功率点: 至少3个重复试样

### 3.2 表征方法
1. **金相分析**: 光学显微镜(50x-1000x) + 图像分割定量
2. **显微硬度**: 维氏硬度计(500gf, 10s)，每试样10个点
3. **XRD**: 物相分析，2θ=30-71°
4. **EIS**: 电化学阻抗谱(100kHz-0.01Hz)
5. **摩擦磨损**: 球盘磨损试验(500g, 10min, 300rpm)

### 3.3 评价指标
- 熔覆层显微硬度(HV): 目标>385 HV
- 气孔率(%): 目标<0.5%
- 裂纹率(%): 目标<0.5%
- 稳态摩擦系数: 目标<0.15
- 腐蚀抗性(Rct): 目标>3000Ω
